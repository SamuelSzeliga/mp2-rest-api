My MP2 has four main endpoints: health response, upload dataset, get dataset id, and process dataset. Health response checks to make sure that the application is running smoothly. The upload dataset endpoint takes in a file and, first, checks to make sure that it is a CSV. If it is, then it will read and parse the data, checking for errors along the way. After that, it saves the data and returns the metadata. The get dataset id endpoint takes in the dataset and returns the amount of rows requested by the client, as well as loading it as a json. Finally, the process dataset endpoint retrieves a copy of the dataset, converts it to a dictionary, checks for missing columns and then validates the dataframe. It logs any rows that were removed during validation, processes the data using a function from the MP1 imports, creates a cleaning report, updates the storage, and returns a processing report.
